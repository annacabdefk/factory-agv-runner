# AGV 无人工厂 · 无线充电挑战

一款纯前端的网页小游戏：主角是一台 AGV 移动机器人，在无人工厂内自动前进换轨，驶过充电区补充电量，拾取货物送往托盘交货；电量耗尽即失败。电脑与手机浏览器均可直接游玩。

## 玩法

- 左右切换轨道，尽量驶过**充电区**补充电量（每经过一次瞬间 +5%）
- 初始电量 80%，约 20 秒内必须完成至少一次充电，否则电量耗尽失败
- 每隔 5 秒有**货物**随机落在路径上，拾取后送往随机出现的**托盘**交货，每交一单 +1 分
- 纯电量管理，无碰撞障碍；无限模式，速度随时间逐渐加快

## 三种充电方式（与威飞能 AGV 实际充电方式对应）

| 类型 | 说明 | 颜色 |
|---|---|---|
| 底充 | 地面感应充电垫 | 青色 |
| 侧充 | 侧向充电臂 | 绿色 |
| 坡道充电 | 倾斜坡道充电平台 | 蓝色 |

## 操作

- 桌面：`←` / `→` 或 `A` / `D` 切换轨道；`P` / `Esc` 暂停；`M` 静音；`空格` / `Enter` 开始
- 手机：左右滑动切换轨道（触控目标均 ≥ 44px）

## 运行

直接用浏览器打开 `index.html` 即可，无需构建、无需联网（音效由 Web Audio 实时合成）。

## 平衡参数

所有可调数值集中在 `game.js` 顶部的 `CFG` 配置对象中，例如：

- `DRAIN_PER_SEC`：每秒耗电百分比
- `CHARGE_AMOUNT`：每次充电恢复电量
- `ZONE_INTERVAL`：充电区生成间隔
- `BASE_SPEED` / `SPEED_RAMP`：基础速度与递增率
